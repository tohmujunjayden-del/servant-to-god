# Servant to God

A playable local 2-player Yu-Gi-Oh!-inspired duel prototype for the repository.

Features:
- 2-player local duel on one screen
- 8,000 LP and win by reducing LP to zero
- Draw, Standby, Main 1, Battle, Main 2, and End phases
- Monster summon and tribute summoning by level
- Monster and direct attacks
- Spell and Trap cards with effects
- Deck, hand, graveyard, and field tracking
- Restart and turn log

Quick start:
1. Open `index.html` in a browser, or run a local server:
   `python -m http.server 8000`
2. Visit `http://localhost:8000`

This is a simplified, original-card duel system inspired by Yu-Gi-Oh! and designed to be extended toward online multiplayer later.
